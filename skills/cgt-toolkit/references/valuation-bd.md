# 估值、交易与商业化

> 用途：给 CGT 资产做 rNPV、设计交易结构、判断定价与支付现实。
> 纪律：算数一律用 `scripts/cgt_calc.py`，参数假设必须在报告里列出来；不引用未经核验的具体交易金额与倍数。

## 一、rNPV 参数基准（起点，不是结论）

| 参数 | 建议区间 | 备注 |
|---|---|---|
| 成功概率 POS（阶段调整） | 临床前 10–20%；临床 I 期 20–30%；II 期 35–50%；III 期 60–80% | 行业基准值，需按适应症、终点选择、已有证据修正；不要直接采用申办方口径 |
| 折现率 | 10–12% | 单一 SME 资产可用更高（12–15%），平台型可略低 |
| 经营利润率 | 30–45% | 自体 CGT 因 COGS 高，商业早期常低于 30% |
| 爬坡年限 | 3–5 年 | 受产能爬坡限制的自体产品应取更长 |
| 专利/独占到期后年衰减 | 10–20% | 生物类似/仿制竞争强度决定 |

**关键点**：CGT 的 POS 不能照抄传统小分子基准，因为制造失败、工艺可比性、长期随访要求都会拉低实际通过率；反过来，罕见病高未满足需求的品种在加速路径下可能高于基准。要把"为什么高于/低于基准"写清楚。

## 二、rNPV 的六个陷阱

1. **把幸存者偏差当成概率**：用已获批产品的路径估 POS，忽略同期失败者。
2. **忽略产能约束**：自体产品峰值销售受批次数限制，不是市场总量限制。先跑 `cgt_calc.py cell` 看每年能覆盖多少患者，再谈峰值。
3. **忽略 COGS 结构变化**：商业化规模下载体成本会降，但 LTFU 与合规成本常上升。
4. **支付现实脱节**：中国百万级定价的自费产品在无商保/惠民保覆盖时，实际渗透率远低于理论患者流。
5. **一次性治愈的收入模型**： curing patient 导致存量池逐年缩小，不能按慢病持续用药模型外推。
6. **对分期/后续治疗竞争估计不足**：同一靶点的双抗、ADC、小分子会在 3–5 年内重塑格局。

## 三、交易结构要点

| 结构 | 适用 | 风险点 |
|---|---|---|
| License-out（区域权益） | 中国资产出海最常见 | 里程碑触发条件与定义（"首个受试者给药" vs "监管批准"）必须精确；回归条款要写清 |
| License-in | 补充管线 | 支付节奏与期权阶段绑定；注意受让方的后续义务（开发努力义务、里程碑期限、终止后权益回转） |
| CVR（或有价值权） | 卖家认为估值被低估 | 触发条件的可实现性与核算口径最易争执；期限通常 5–10 年 |
| Co-development / 联合开发 | 双方均有能力 | 决策机制、费用分摊、数据归属、终止后的资料返还 |
| NewCo / spin-out | 平台变现 | 知识产权隔离（field of use）、员工安排、后续融资摊薄 |

**条款清单（尽调必看）**：是否含中国区权益保留；里程碑是否为排他合计且可否触发；开发努力义务与放弃条款；终止后 license 的回转；数据与安全监查资料的移交；后续研发投入的分担；制裁/出口管制与人类遗传资源合规是否影响协议执行。

## 四、中国定价与支付现实

- **价格量级**：已上市 CAR-T 产品定价普遍在百万元人民币量级；具体品种价格与支付方式变化快，引用时必须核验最新信息。
- **支付结构**：基本医保为主 + 惠民保/城市定制型医疗险 + 商业健康险 + 患者援助/分期。惠民保的实际赔付比例与封顶线是决定渗透率的变量。
- **渠道**：具备细胞治疗能力的医院数量有限，采血—制备—回输链路要求高，患者流向集中度高。
- **产能与需求匹配**：先算"能服务多少例"，再算"有多少患者"，顺序反了估值会虚高。

## 五、COGS 与定价敏感度

用 `scripts/cgt_calc.py cogs` 做拆解，判断标准：

- 自体 CGT：COGS 占终端价格通常应低于 35%，超过则商业模型脆弱。
- 异体/通用型：规模化后目标低于 25%，但要扣除编辑、筛查与冷链增量。
- 载体占比高于 50% 时，优先做滴度提升与 MOI 下调，而不是压人工。

## 六、估值输出模板

| 部分 | 内容 |
|---|---|
| 核心假设表 | 参数 / 取值 / 依据 / 敏感性排序 |
| 人群流 | 流行病学 → 可诊断 → 可及 → 可接受治疗 → 实际渗透，逐年给出折损原因 |
| 产能表 | 单批可覆盖人数、年批次数上限、由此约束的年可治疗人数 |
| 财务表 | 分年收入、成本、毛利、现金流 |
| 敏感性 | 至少峰值销售 ±20%、POS ±20%、上市推迟 2 年、折现率 8%/12% |
| 结论 | rNPV 区间、关键敏感性变量、"什么事发生了就该重估" |
