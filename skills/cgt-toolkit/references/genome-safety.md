# 基因组安全与长期随访

> 用途：判断一个基因编辑或整合型载体产品的基因组安全性包是否足以支持 IND/BLA，以及 LTFU 方案是否可执行。
> 口径提醒：VCN 写 copies/diploid genome 还是 copies/µg DNA；编辑率写 % indel 还是等位基因百分比；脱靶灵敏度写检出限（如 0.1% VAF）。口径不统一会导致数据不可比。

## 一、脱靶评估的三层组合（缺一层通常立不住）

| 层次 | 方法 | 能说明什么 | 局限 |
|---|---|---|---|
| 计算预测 | gRNA 序列比对 + 错配打分（如 CFD 类算法） | 给出候选名单与优先级 | 不能反映真实染色质状态，会漏也会误报 |
| 无偏生化/细胞实验 | GUIDE-seq、CIRCLE-seq、DISCOVER-seq、SITE-seq 等 | 不依赖预测的实验性位点发现 | 不同方法灵敏度与偏好差异大，单用一种不够 |
| 临床批/产品的靶向验证 | 候选位点的靶向扩增测序（amp-NGS） | 实际产品批次上的验证，可直接作为放行关联数据 | 依赖前两层提供名单 |

**常见失分**：
- 只用生物信息学预测，没有实验层。
- 只做 GUIDE-seq，没做 Orthogonal 方法交叉验证。
- 候选位点验证的测序深度不足，检出限达不到申报要求（通常需达到 ≤0.1% VAF 量级，具体按产品与监管要求定）。
- 碱基编辑/先导编辑没有考虑 RNA 层面的脱靶（转录组范围 deamination/off-target）。

## 二、在靶非预期效应（常被忽略）

编辑「打中了」也可能很危险：

1. **大片段缺失**：单一切点即可引发数 kb 甚至更大的缺失。
2. **染色体易位与重排**：多靶点编辑时风险显著升高。
3. **染色体级异常**：非整倍体、大片段缺失需用长读长测序或光学图谱补充评估（短读长可能漏掉）。
4. **克隆性造血驱动突变**：离体 HSC 编辑产品要评估 DNMT3A、TET2、ASXL1 等 CH 相关基因的克隆动态。
5. **p53 通路压力下的克隆选择**：编辑压力可能筛出 p53 缺陷克隆，需评估其在回输群体中的占比。

## 三、插入位点与整合型载体

- **LVV/逆转录病毒**：偏好转录活跃区域，整合位点谱本身不是安全缺陷，但克隆性异常增殖是。
- **评估方法**：LAM-PCR、shearing 法 IS-seq 或靶向测序；关键指标包括插入位点数量、独特性、克隆多样性指数、是否有克隆占比持续上升。
- **长期监控**：先天/肿瘤相关基因附近的克隆（原癌基因附近插入）需要长期随访，一旦发现克隆优势需风险评估上报。
- **转座酶系统**（如 Sleeping Beauty、piggyBac）：随机性更高，克隆筛查负担更大。
- **非整合型 AAV**：仍存在低频率染色体整合，尤其在高剂量与肝脏肿瘤背景下需要长期评估，不能简单声明"不整合即可豁免"。

## 四、致瘤性与非临床安全评估

| 问题 | 非临床怎么答 |
|---|---|
| 修饰细胞会不会不受控增殖 | 体外永生化/转化assay（如软琼脂克隆形成、生长曲线平台）、体内分布与致瘤性（免疫缺陷动物）长期观察 |
| 编辑本身会不会诱发转化 | 编辑后群体的长期培养 + 基因组稳定性 + p53 通路状态分析 |
| 载体会不会导致生殖系整合 | 性腺/生殖细胞的分布研究（按产品与监管要求安排） |
| 免疫原性 | 抗 Cas9 / 抗 PAM-less / 抗载体衣壳抗体的产生时间、中和活性、对重复给药的影响；预存中和抗体对 AAV 给药的排除标准 |
| 载体脱落 | 血、尿、唾液、粪便的脱落动力学，服务于环境释放与接触者风险评估 |

## 五、长期随访（LTFU）设计要点

1. **年限**：整合型载体与基因编辑产品通常 15 年；非整合型 AAV 常 5 年。以审批承诺为准，写入上市后承诺。
2. **可执行性比年限更重要**：随访表设计、受试者联系机制、数据管理平台、年度预算，缺一项都无法兑现。
3. **最小数据集**：生存状态、恶性肿瘤发生、神经系统事件、自身免疫/血液学异常、生育相关结局（适龄人群）、必要时的载体分子检测。
4. **对照组/背景发病率**：没有背景率作对照的零星个案报告难以解释，罕见事件尤其需要与疾病人群背景率比较。
5. **真实世界数据来源**：患者登记、肿瘤登记、电子病历联动，可显著降低随访成本，但需数据合规（知情同意、数据出境规则）。

## 六、审评最常问的十个问题

1. 脱靶评估为什么只用一种方法？
2. 在靶大片段缺失和染色体异常查了吗？短读长测序能覆盖吗？
3. 整合位点分析的样本量、时间点、克隆多样性指数是多少？
4. 是否观察到克隆优势扩大？趋势如何解释？
5. 阳性临界值与临床批放行标准怎么定的？
6. 编辑产物的异质性（部分编辑、等位基因缺失）如何控制与检测？
7. 抗 Cas9 / 抗衣壳抗体对重复给药的影响评估了吗？
8. 载体脱落数据在哪一种体液、什么时候阳性？
9. LTFU 计划谁执行、钱谁出、失访率怎么控？
10. 上一版本工艺变更后，基因组安全性数据是否重新桥接？

## 七、输出纪律

- 只做研究层面的证据梳理与制度设计，不判定"某产品是否致癌"这类结论（需要人群数据与安全信号评估）。
- 不给个体患者的医学建议。
- 涉及基因编辑的生殖系与胚胎相关应用，一律不提供操作路径（属禁止/严格管制范畴），只说明合规边界。
