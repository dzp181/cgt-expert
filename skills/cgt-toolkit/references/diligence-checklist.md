# 立项与 BD 尽调清单

> 用途：给 CGT 项目做技术尽调、立项评审、投委会材料。八个维度逐项打分并标注证据等级，避免被"平台故事"带着走。
> 用法：每个维度看一遍，能答Yes 给 2 分、需补充 1 分、答不上或没有 0 分；总分 <18/32 的项目不建议推进。

## 一、科学与靶点（8 项）

- [ ] 靶抗原的正常组织表达谱有完整数据（蛋白 + mRNA 双重证据，含关键器官）。
- [ ] 抗原密度达到该疗法激活阈值，且有定量依据（不是"文献报道阳性"）。
- [ ] On-target off-tumor 的最坏场景被明确写出，并有对应的安全性开关或剂量冗余。
- [ ] 抗原脱落与异质性已评估（制定细胞系/原代样本的阳性率数据）。
- [ ] 逃逸机制有预案（双靶、串联不同的 co-stimulatory design、序贯策略）。
- [ ] 非临床模型能反映人类疾病的关键特征（不要用只反映单细胞系异种移植的数据替代）。
- [ ] 已知同类机制失败的原因有清晰解释，且本项目针对该原因有实质改动。
- [ ] 存在可行的主要终点 candidats（能够在合理时间内测量且与获益关联）。

## 二、CMC 与工艺（6 项）

- [ ] 关键物料（质粒、病毒载体、磁珠、培养基）双源或至少有备选 + 交期数据。
- [ ] 至少连续 3 批的代表性批次放行数据完整且达标。
- [ ] 效力 assay 与临床疗效的关联有探索性数据（不是只有体外杀伤率）。
- [ ] VCN / 空壳率 / 编辑率等关键参数的批间变异可接受（CV 有数据）。
- [ ] 单例 COGS 有拆解表，且能支撑目标定价。
- [ ] 静脉-静脉周期（或上市交付周期）符合目标适应症患者的疾病进程。

## 三、临床开发（6 项）

- [ ] 目标适应症、线数、人群与排除标准清晰，招募可行性有数据支撑。
- [ ] 主要终点、次要终点、探索性终点三层设计合理，且有中心化评估安排。
- [ ] DLT 观察窗与安全性管理方案（CRS/ICANS/肝毒性/神经毒性）齐全。
- [ ] 与现有最佳疗法的对照策略明确（历史对照质量、确证性试验规划）。- [ ] 长期随访要求的成本与执行机制已预算并落实责任主体。
- [ ] 特殊人群扩展计划（儿科、器官功能不全）有初步考虑。

## 四、法规路径（4 项）

- [ ] 明确确定为药品路径还是生物医学新技术路径，且有法规依据（文号 + 生效日）。
- [ ] 若为国内新技术路径，实施机构资质与备案资料准备度核过。
- [ ] 目标海外市场的 USA/EU 路径、加速工具适用性、CMC 就绪度评估完成。
- [ ] 人类遗传资源、选择 grid 与数据出境合规无硬伤。

## 五、知识产权（4 项）

- [ ] 核心序列/结构（CAR/TCR/衣壳/编辑器/脂质）FTO 检索完成。
- [ ] 自有专利的保护范围足以覆盖目标产品，且地域与期限匹配商业计划。
- [ ] 载体/细胞株/细胞系的材料转移协议（MTA）允许商业化使用。
- [ ] 与 CDMO / 学术机构的成果归属无未决争议。

## 六、团队与执行（4 项）

- [ ] 工艺、质量、临床、注册四个关键职能均有可联络到的责任人（不超过外包依赖）。
- [ ] CDMO 排产与合同条款（优先级、交付周期、违约责任）明确。
- [ ] 核心科学创始人/CSO 的投入度与留存安排清晰。
- [ ] 出现过的关键失败（批次报废、临床暂停）复盘记录可查。

## 七、商业与支付（6 项）

- [ ] 目标患者池按"可得 → 可诊断 → 可及 → 可接受治疗"逐级折损测算过。
- [ ] 定价假设有可比品种与支付方调研支撑（不是管理层目标价）。
- [ ] 产能年可治疗人数已算过，且峰值销售不超过产能上限。
- [ ] 支付路径（医保/惠民保/商保/PAP）具体到省市或主要商保产品层面。
- [ ] 渠道医院数量与分布（采血—制备—回输能力）有清单。
- [ ] 替代威胁（双抗/ADC/小分子/移植/放疗）的时间窗口评估完成。

## 八、交易/投资条款（4 项）

- [ ] 里程碑定义与触发条件精确到可核事件，"首个受试者给药"与"监管批准"不混用。
- [ ] CVR / 优先受让 / 反稀释 / 回购 / 清算优先权条款已模拟过至少 3 个情景。
- [ ] 终止后 IP、监管档案、临床数据的归属与移交路径写清。
- [ ] 对赌与开发努力义务可执行且有争议解决机制。

## 九、Kill criteria（出现即重估或停止）

1. **科学层**：机制上无法解释观察到的疗效差异；或ON-target off-tumor 的最坏场景发生在关键器官。
2. **工艺层**：连续 3 批中存在 VCN / 空壳率 / 活率的关键指标不合格且原因不明；或批失败率 >15% 且整改无路径。
3. **临床层**：ORR 低于同线数历史对照的显著区间；或 DoR 短于同类产品的可比对水平，需重算商业模型。
4. **安全层**：出现同类预期的严重迟发毒性（继发肿瘤、染色体异常克隆）且无管理手段。
5. **商业层**：单例 COGS > 目标定价的 40%，或年产能不足商业计划目标的 50%。
6. **合规层**：人类遗传资源、外包 CGMP、数据出境存在不可逆违规风险。
7. **IP 层**：核心要素 FTO 被判高风险且无规避设计。

## 十、红旗信号（看到就先别投）

- 只有 IIT 数据，没有 GLP 毒理代表性批次与放行数据，却声称"即将 IND"。
- 效力 assay 尚未建立，却已经在谈工艺放大。
- 讲"平台"但只有一个 PCC，且平台产出没有第二款验证了速度优势。
- 未解决载体供应就承诺 12 个月内进入临床。
- 同一批核心人员同时担任多家同类公司关键职务，投入度与利益冲突存疑。
- 财务模型里现金流从上市当年起立即达到峰值销售。

## 十一、尽调交付模板

| 章节 | 内容 |
|---|---|
| 一句话结论 | 推进 / 有条件推进 / 不推进，及唯一最关键的理由 |
| 八维评分表 | 维度 / 得分 / 证据等级（公开数据/企业资料/专家判断）/ 关键缺口 |
| 关键假设检验 | 列出决定项目成败的 5 条假设，逐条给出验证方法与所需时间成本 |
| Kill criteria | 针对本项目的具体判据（带量化阈值） |
| 下一步 | 30/60/90 天动作清单与责任人 |
