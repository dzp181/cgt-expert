# 竞争格局与差异化定位

> 时效强提示：本文件描述的是**判断维度与方法**，企业管线状态、获批产品数量、临床数据与市场格局按月变化。凡涉及"已获批数量""某靶点在研项目数""某公司处于什么阶段"的具体数字，必须以公开信息核验后引用，并标注信息截止时间。

## 一、盘格局的五个维度

1. **靶点拥挤度**：同靶点全球在研数量、已进入注册阶段的个数、中国 vs 全球分布。拥挤度高的靶点，差异化必须从"换个靶点"转向"更好的产品属性"（持久性、安全性、可及性、给药便利）。
2. **机制代际**：第一代（单结构域、单一抗原、病毒转导）→ 第二代（共刺激优化、装甲化、双靶、自杀开关）→ 第三代（体内生成、可控开关、通用型、非病毒递送）。处在低代际且无属性优势的项目基本没有商业空间。
3. **适应症与线数**：同一靶点在不同线数的竞争格局完全不同。末线拥挤时向更早线数推进要付出更高的安全性代价与更长的随访要求。
4. **制造与可及性**：快速制备（缩短静脉-静脉周期）、无需桥接治疗、门急诊可给二醇、床旁/本地化制造，这些属性在拥挤靶点上往往比 ORR 高 5 个百分点更有价值。
5. **区域制度差异**：中国走药品路径 vs 生物医学新技术路径的可行性、支付环境；美国 RMAT 与 CMCP 就绪要求；欧盟 ATMP 与成员国执行差异。

## 二、靶点/技术类型的拥挤度判读（结构示例，不代表实时数据）

| 类别 | 代表靶点或技术 | 拥挤的一般性判读 |
|---|---|---|
| 血液瘤成熟靶点 | CD19、BCMA | 全球在研与已上市密集，差异化窗口收窄到安全性、给药便利与线数前移 |
| 血液瘤新靶点 | GPRC5D、FcRH5、CD70、SLAMF7 | 相对拥挤度较低，但需证明在 BCMA/CD19 暴露或耐药后的独立价值 |
| 实体瘤表达型抗原 | CLDN18.2、GPC3、MSLN、HER2、DLL3、PSMA | 拥挤度高；核心问题是 on-target off-tumor 与浸润不足，不是缺项目 |
| TCR 路线 | NY-ESO-1、KRAS G12D/G12V、HPV E6/E7、HBV | HLA 限制性决定可及人群大小，拥挤度低于 CAR，但商业化难度更大 |
| AAV 靶器官 | 肝脏（凝血因子、代谢病）、中枢（SMA 类）、视网膜 | 肝脏方向最为拥挤且高剂量毒性边界明确；CNS 的鞘内递送与 DRG 毒性是门槛 |
| 基因编辑 | 离体 HSC 编辑（血红蛋白病、免疫缺陷）、体内肝脏编辑 | 平台集中度高，专利布局密集交叉；首要风险是 FTO 与 IP，而非科学本身 |
| iPSC/通用型 NK | iPSC-NK、CAR-NK、脐带血来源 | 中国参与者较多，瓶颈是体内存留时间短、需多次给药带来的支付负担 |
| 体内 CAR-T | LNP-mRNA、靶向脂质纳米颗粒、工程化病毒 | 早期热门，核心壁垒是选择性靶向与可重复给药；故事多，数据仍少 |

## 三、差异化定位的四象限

用下面两个轴给项目定位——横轴：**相对现有最佳疗法的增量价值**（疗效 / 持久性 / 安全性 / 便利性）；纵轴：**可实现性**（制造、注册、支付、产能）。

- 右上（高价值 + 高可实现）：值得投入，尽快把证据做厚。
- 右下（高价值 + 低可实现）：先解决工艺或支付瓶颈，否则是纸面价值。
- 左上（低价值 + 高可实现）：容易做成但没有商业回报，通常用于辅佐产品线。
- 左下（低价值 + 低可实现）：应当停止。

## 四、写竞争格局结论的规矩

1. 先写信息截止时间与数据来源类型（公开数据库、企业公告、会议摘要、审评文件）。
2. 分层描述：全球 / 中国；同靶点 / 同类技术 / 同适应症。不要混在一张表里。
3. 任何具体数量都写"约"并标注需核验；无法核验的内容改为描述结构（如"该靶点已有多个进入注册阶段的项目"）。
4. 差异化结论必须落到可测量的指标上：ORR、DoR、MRD 阴性率、CRS 发生率、静脉-静脉周期、单例成本、是否需桥接。
5. 明确指出"最可能的替代威胁"来自哪一类（双抗/ADC/小分子/移植/放疗），而不是只盯同靶点 CGT。

## 五、不要做的事

- 不虚构"某产品即将获批""某公司进度领先两个身位"这类断言。
- 不用未公开信息做判断；不推测未披露的临床数据。
- 不把"赛道热"当论据：管线数量本身不构成投资理由，也不构成技术判断。
