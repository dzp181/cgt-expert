# 临床开发与注册路径

> 时效提示：本节引用中国国务院第 818 号令（2026-05-01 施行）、第 828 号令《药品管理法实施条例》（2026-05-15 施行），以及 FDA/CBER 的 RMAT 机制（2026 年 3 月起，IND 处于临床暂停不再一并否决 RMAT 资格）。法规与配套文件更新快，正式申报前必须核验最新版原文。

## 一、先确定"它是药还是技术"（中国）

中国 CGT 是**双轨**结构：

| 维度 | 药品路径 | 生物医学新技术路径 |
|---|---|---|
| 监管主体 | NMPA（药品）：细胞治疗产品按生物制品/新型药品管理，IND → 临床 → 上市申请 | 卫健主管部门：临床研究备案 + 临床转化应用审批 |
| 核心法规 | 《药品管理法》《药品管理法实施条例》（国务院第 828 号令，2026-05-15 施行，明确细胞治疗产品的新型药品定位） | 《生物医学新技术临床研究和临床转化应用管理条例》（国务院第 818 号令，2026-05-01 施行） |
| 核心流程 | IND 递交 → 临床试验 → 注册申报 | 非临床充分验证 → 临床研究备案 → 临床转化应用审批 |
| 实施机构 | 具备药物临床试验机构资质 | 实施临床研究的机构须为三级甲等医疗机构等法定条件 |
| 时限 | 按药品审评审批时限，可争取突破性治疗药物、优先审评等加快通道 | 备案后按规定的工作日时限上报；临床转化应用审批按"启动评估 5 个工作日 + 作出决定 15 个工作日"的节奏执行 |
| 适用 | 拟规模化上市、需要全国商业流通的产品 | 个体化程度高、以医疗机构为主体的新技术研究与转化应用 |

**实践要点**

- 两者不是"绕开哪个"的关系。目标是全国商业化销售的产品，药品路径是唯一合规出口；新技术路径适用于医疗机构主导的研究与转化应用。
- 818 号令下，企业可以作为临床研究发起机构独立申请备案，不再只是合作方或资助方，这对高个体化 CGT 技术是实质利好；但备案资料完整度接近 IND 要求，非临床研究能力成为硬门槛。
- 配套文件（如《生物医学新技术与药品、医疗器械界定指导原则（暂行）》《生物医学新技术临床转化应用审批工作规范（试行）》及备案指引）是判断走哪条轨道的第一依据，先做界定再谈路径。
- **不以 IIT 之名行商业销售之实**，这是红线。

## 二、FDA（CBER / OTP）

- 产品形态：细胞与基因治疗产品按 PHS Act 351 管理，需 IND 开展临床、以 BLA 上市。符合 361 HCT/P 条件（最小操作、同源使用等）的组织产品另有规则。
- 加速工具：Fast Track、Breakthrough Therapy、RMAT、Priority Review、Accelerated Approval。RMAT 需要**初步临床证据**（非临床数据不够），CBER 在收到申请后 60 个自然日内答复。2026 年 3 月起，IND 处于临床暂停不再自动否决 RMAT 资格，安全管控与加速资格分开评估。
- CMC 灵活性：OTP 推行分阶段 cGMP（phase-appropriate cGMP）——早期不要求商业化制造标准，但质量、安全与过程控制不能缺席；随试验推进逐步收紧至工艺验证、可比性与质量体系。
- 支持性试点：CMC Development and Readiness Pilot（CMC 就绪）、START Pilot（罕见病）、RDEA（终点开发）等，适合早期争取密集监管互动。**具体试点名称与受理状态需核验最新公告。**
- 基因组安全：FDA 已就"用测序方法评估基因治疗（尤其基因编辑产品）安全性"发布指南类文件，重点是脱靶、在靶非预期效应、染色体重排与基因组完整性。**征求意见稿与终版状态需核验。**

## 三、EMA / 欧盟

- ATMP（先进治疗医药产品）由 CAT 负责分类与科学建议，包含基因治疗、体细胞治疗与组织工程产品；允许医院豁免（Hospital Exemption，成员国差异较大）。
- 孤儿药认定 + PRIME + 加速评估 + 条件性上市许可的组合使用。
- 额外要求：转基因生物的 environment risk 评估、区域伦理与成员国层面的执行差异。
- 长期随访（LTFU）：整合型载体与基因编辑产品通常 15 年，非整合型（AAV）按风险常为 5 年，具体以审批承诺为准。

## 四、剂量探索设计要点

1. **单次给药的特性**：CGT 多为单次给药，没有传统稳态 PK；剂量递增处理的是"暴露—扩增—疗效—毒性"的耦合关系。
2. **DLT 观察窗**：必须覆盖预期毒性窗口。CAR-T 需覆盖 CRS/ICANS 高峰期（通常前 2–4 周，部分毒性更长）；AAV 的免疫性肝毒性可在首次给药后数周出现，存在延迟 DLT。
3. **递增方法**：3+3 简单但信息密度低；BOIN / mTPI-2 等模型辅助设计更高效。选择取决于容错空间与是否需要描绘剂量—效应曲线形状。
4. **降级预设**：出现 DLT 后的处理路径要预先写入方案，并区分"不可耐受剂量"与"推荐剂量"。
5. **按体重 vs 固定剂量**：先看目标是系统暴露还是局部暴露，再用 PK/PD 或载体分布证据做桥接，不能等到商业化阶段才改。
6. **桥接治疗**：清淋前是否允许桥接、允许什么方案，直接决定入组可行性与人群一致性，必须写明。
7. **特殊人群**：儿科是否可从成人外推要有合理依据；老年人与器官功能不全者常先排除再扩展。

## 五、终点体系（按适用）

| 终点 | 适用场景 | 常见陷阱 |
|---|---|---|
| ORR（CR/sCR + PR） | 血液瘤单臂探索 | 反应率好看不等于临床获益；评估标准（IMWG、Lugano、RECIL）需全员统一，建议中心化 IRC 审阅 |
| DoR / MRD 阴性率 | 支持持久性 | MRD 检测灵敏度（10^-5 与 10^-6 差一个数量级）必须写清方法与阈值 |
| EFS / PFS | 随机对照 | 事件定义要包含制造失败、无法回输等 CGT 特有事件 |
| OS | 最终标准 | 交叉治疗与后续疗法稀释效应，需预设处理策略 |
| 功能或生化替代终点 | 罕见病、遗传病 | 必须论证与临床获益的关联，否则不宜作为注册终点 |

**单臂注册成立的三个常识基准**：历史对照清晰且可比；ORR 相较历史明显改善且 DoR 支持；确证性试验在申报时已启动或紧密推进。具体门槛按适应症与监管机构确定，不要套用单个先例。

## 六、安全性监测重点

- **CRS**：按 ASTCT 共识分级（Lee et al., 2019）处置，托珠单抗 ± 激素是关键决策点。
- **ICANS**：独立评估（如 ICE 评分），不与 CRS 混为一谈；监测频率、激素阈值、癫痫预防需写进方案。
- **长期随访**：整合型载体与基因编辑产品通常 15 年，须提前设计随访登记表、可执行的受试者再联系机制，并预算由此产生的常年成本。
- **继发恶性肿瘤**：已成为 CAR-T 类产品必须正面回应的风险，告知书与说明书要体现，审评会追问监测与报告机制。
- **生殖系传递**：基因编辑产品需做非临床评估并按监管要求在临床长期随访中安排相应检测。

## 七、注册路径输出模板

| 交付物 | 内容要求 |
|---|---|
| 路径表 | 目标市场 / 产品属性（药品 vs 生物医学新技术）/ 适用法规（文号 + 生效日）/ 前置条件 |
| 时间轴 | Pre-IND / IND / 临床各期 / 上市申请，每个节点的前置条件与依赖关系 |
| 关键风险 | CMC 就绪度、非临床数据完整性、临床执行力、LTFU 承担的长期成本 |
| 决策点 | 何时适用 818 号令路径、何时必须转药品路径、何时申请 RMAT / 突破性 / 优先审评 |
| 未决事项 | 需要预沟通或专业注册咨询的问题清单 |

## 八、不能做的事

- 不虚构法规条款号、批准日期、批件号；不确定时写明"按最新版官方文件核验"。
- 不设计"先做若干例 IIT 再上市"的规避方案。
- 不给具体患者的用药与处置建议。
- 不承诺审批结果或时限保证，只给基于公开规则的合理预期区间与依据。
