# CMC 与放行

> 用途：设计放行项、效力方法、可比性方案，以及判断 CMC 是不是项目的真实瓶颈。
> 口径提醒：VCN 写 copies/diploid genome 还是 copies/µg DNA；滴度写 vg/mL（粗纯/成品）还是 TU/mL；细胞数写 CAR+ 还是总活细胞。混用是审评最常见的低级失分点。

## 一、物料链

**细胞治疗（自体）**：外周血单个核细胞采集 → T 细胞分选/活化 → 转导（LVV/逆转录病毒）或编辑（RNP 电转）→ 扩增 → 收获洗涤 → 制剂冻存 → 放行 → 冷链到院 → 复融回输。

**病毒载体**：质粒（三种/四种）→ 细胞扩增 → 转染（PEI/悬浮）→ 上游培养 → 收获澄清 → 下游纯化（亲和 + 精纯/阴离子交换）→ 除菌过滤 → 配方 → 冻存。AAV 的关键指标是实心率（full/empty ratio），LVV 是感染滴度与功能滴度的一致性。

**关键判断**：
- 质粒是上游咽喉，GMP 质粒交期常 8–12 周，工艺放大与临床推进节奏受它约束。
- AAV 空壳率从 70% 降到 20% 通常比提滴度更能降 COGS，因为空壳占用免疫剂量但不贡献效力。
- LVV 瞬时转染的批间差异主要来自转染效率与细胞状态，不是纯化。

## 二、放行项（按产品类型）

### 细胞治疗产品

| 类别 | 项目 | 方法与常见坑 |
|---|---|---|
| 身份 | 细胞表型（CD3+/CD4/CD8/记忆亚群）、CAR 阳性率 | 流式抗体克隆号需固定；CAR 检测用蛋白 L 或多聚体，两者结果不可直接互比 |
| 纯度 | 活细胞比例、残留磁珠/微珠、残留鼠源抗体 | 冻存后活率比收获时低 10–15 个百分点，规格要按复融后定 |
| 效力 | 抗原依赖性杀伤、细胞因子释放、增殖 | 至少一个与机制相关；只报"杀伤率"不够，需设效价单位或相对效力 |
| 载体拷贝数 | VCN（copies/diploid genome） | qPCR 标准曲线与参考基因选择影响结果；设上限 ≤5 是常见做法 |
| 复制型病毒 | RCL（LVV 产品） | 共培养法周期长（数周），需提前排产；检测灵敏度要写清 |
| 微生物 | 无菌、支原体、内毒素、外源病毒 | 自体产品常需快速方法（快速微生物检测）以缩短放行 |
| 残留 | 残留 DNA、宿主蛋白、BSA、DNase、血清 | 转导用培养基组分要建残留方法 |
| 其他 | 外观、装量、可见异物、渗透压、pH | 冻存保护剂（DMSO）浓度需固定 |

### AAV 产品

| 类别 | 项目 | 说明 |
|---|---|---|
| 身份 | 衣壳蛋白序列/血清型鉴定、转基因序列 | 工程化衣壳需做肽段/全序列确认 |
| 含量 | 滴度（vg/mL，ddPCR/qPCR）、实心率 | 优先用 ddPCR；实心率用 AUC/CE 或质谱 |
| 效力 | 体外转导/表达（细胞模型）、必要时体内效价 | 体外效力与临床相关性弱是常见缺陷，需论证 |
| 杂质 | 残留 DNA（质粒/宿主）、残留蛋白、空壳、聚集 | 空壳是 AAV 特有的放行与稳定性指标 |
| 复制型 AAV | rcAAV | 灵敏度按方法学定，通常要求低于检测限 |
| 安全 | 无菌、内毒素、支原体、外源病毒 | 同生物制品通则 |
| 脱落 | 非临床阶段的载体脱落（血/尿/分泌液） | 临床前完成，支持环境风险评估 |

## 三、效力 assay 的三条底线

1. **机制相关**：方法测的生物学步骤必须与临床作用机制对应（CAR-T 的抗原依赖性激活，AAV 的转导与表达，编辑产品的编辑效率）。
2. **可定量、有参照**：设内部参考品，报告相对效力（% of reference），并给出批间变异（CV）。
3. **工艺变更后可桥接**：方法本身要能区分"更好/更差"，否则可比性研究无从谈起。

> 审评最常见的问题不是"没有效力方法"，而是"效力方法与疗效无相关性"。早期就该做效力—暴露—疗效的相关性探索。

## 四、可比性研究（工艺变更）

触发场景：场地转移、规模放大、培养基/载体供应商变更、转导方式改变（如从静态转导改离心转导）、编辑方式改变（质粒→RNP）。

最小可比性包：
- 批记录与工艺参数对比（关键工艺参数 CPP 差异清单）。
- 至少 3 批变更后工艺的工程批/临床批数据。
- 放行全项对比 + 扩展表征（表型、VCN 分布、整合位点、效力、纯度）。
- 稳定性对比（至少加速与长期各一组）。
- 如变更影响暴露或效力，需临床桥接（PK/PD 或疗效可比性）。

## 五、稳定性与供应链

- 自体细胞产品：冻存制剂 −196℃ 气相液氮，稳定性通常 2–3 年，需做运输验证（干冰/液氮转运箱、温度记录仪）。
- AAV：−60℃ 以下，冻融循环次数是硬约束，临床上限制"复融后不得再冻"。
- 供应链双源：质粒、培养基、血清替代物、一次性反应袋、病毒载体 CDMO 产能，任何单一来源都是断供风险。
- 放行周期：自体产品放行 5–10 个工作日是竞争力的一部分，快速微生物学方法与快速支原体方法值得提前投入。

## 六、COGS 抓手（按杠杆大小排序）

1. **空壳率与滴度**（AAV）：直接决定单剂载体成本。
2. **MOI 与转导效率**（细胞）：MOI 从 10 降到 3，载体成本降 70%。
3. **批失败率**：8% → 3%，等效于所有成本下降 5% 以上，且减少患者重采。
4. **放行周期**：缩短住院等待，间接提升产能周转。
5. **自动化与封闭系统**：降低人工与洁净区等级要求，但设备折旧要算进去。
6. **国产替代**：培养基、磁珠、质粒、酶，价格差可达 50%，但要重做可比性。

## 七、给结论时的写法

- 先判"CMC 是不是瓶颈"：如果单例 COGS 占定价 40% 以上、或放行失败率 >10%、或关键物料单一来源，答案是"是"，其余优化都是次要的。
- 放行项给表：`项目 / 方法 / 规格 / 依据 / 风险`。
- 不承诺合规结论：GMP 状态只能现场审计确认，输出的是差距清单与整改优先级。
