# 技术路线与选型

> 用途：判断某个适应症该走哪条 CGT 路线，以及在什么条件下这条路走不通。
> 时效提示：具体产品获批状态与临床数据变化快，引用时须核验；本文件给的是判断框架与机制约束。

## 一、路线全景

| 路线 | 载荷/载体 | 持久性 | 给药 | 制造复杂度 | 主要风险 | 典型适应症 |
|---|---|---|---|---|---|---|
| 自体 CAR-T | LVV/逆转录病毒转导，或 CRISPR 敲入 | 数年（记忆亚群可更长） | 清淋后单次回输 | 高（单例单批、静脉-静脉 3–5 周） | CRS/ICANS、继发 T 细胞肿瘤、制造失败 | B 细胞恶性肿瘤、多发性骨髓瘤、部分实体瘤 |
| 异体 CAR-T/NK | 同上 + 基因编辑去除 TCR/HLA | 数天至数周（被排斥） | 可多次 | 中高（可批量化，但需编辑与筛查） | GVHD、宿主排斥、持久性不足 | 血液瘤、通用化需求场景 |
| TCR-T | LVV 导入 TCRα/β 链 | 较长 | 清淋后回输 | 高（需 HLA 分型、配对链错配控制） | 交叉反应、on-target off-tumor | 滑膜肉瘤、黑色素瘤、病毒相关肿瘤 |
| TIL | 手术取材 + 体外扩增，无需基因修饰 | 中等 | 清淋 + IL-2 | 高（需可切除病灶、扩增失败率高） | 扩增失败、IL-2 毒性 | 晚期黑色素瘤、宫颈癌、部分实体瘤 |
| HSC 基因治疗 | LVV 转导 CD34+ 或 CRISPR 编辑 | 终身（自我更新） | 清淋/白消安预处理后回输 | 极高（CD34+ 动员、转导、植入） | 植入失败、克隆性造血、插入突变 | 输血依赖型 β-地贫、SCID、HLH、脑肾上腺脑白质营养不良 |
| 体内 AAV | AAV 衣壳（多血清型/工程化） | 非整合，肝内可数年；增殖组织丢失 | 静脉/鞘内/视网膜下/局部 | 高（空壳率、滴度、免疫） | 肝毒性、补体激活、TMA、DRG 毒性、抗体阳性排除 | 脊髓性肌萎缩、血友病、遗传性视网膜病、神经肌肉病 |
| 体内 LNP-mRNA | 脂质纳米颗粒 | 数天至数周（瞬时） | 静脉/局部 | 中高（mRNA 与 LNP 两步） | 重复给药免疫、肝外靶向性差 | 疫苗、体内编辑（瞬时）、体内 CAR-T |
| 离体基因编辑 | RNP/电转（Cas9、碱基编辑、先导编辑） | 依细胞类型 | 回输 | 高（编辑效率、脱靶、染色体异常） | 脱靶、大片段缺失、易位 | 血红蛋白病、原发性免疫缺陷 |
| 溶瘤病毒 | HSV/腺病毒/呼肠孤病毒等 | 有限复制 | 瘤内/静脉 | 中高（复制型载体放行） | 播散、环境释放、免疫抑制患者风险 | 黑色素瘤、胶质瘤、膀胱癌 |

## 二、选型的六个硬约束

按顺序问，任何一条答不上来就不要进下一步。

1. **靶抗原是否成立**：正常组织表达谱（on-target off-tumor）、抗原密度（低密度下 CAR 是否还能激活）、是否可溶性脱落（shed antigen 占位）、是否均一表达（异质性导致抗原阴性逃逸）。
2. **载荷装得下吗**：AAV ≤4.7 kb（含 ITR）；LVV ≈8 kb。装不下就要换载体、拆双载体、或改调控元件——这一步决定项目生死，不是后期优化能解决的。
3. **持久性需求**：遗传病要终身表达（整合型载体或 HSC 编辑）；肿瘤杀伤只需数周至数月（LNP-mRNA 瞬时即可）；反复给药是否可行（免疫原性决定）。
4. **给药途径与剂量窗口**：全身给药的 AAV 剂量已到 1×10^14 vg/kg 量级，肝毒性与补体是天花板；瘤内给药受病灶可及性限制。
5. **患者 T 细胞质量**：多线治疗后 T 细胞耗竭、既往苯达莫司汀/氟达拉滨暴露、淋巴细胞绝对数低，直接决定制造成功率与体内扩增。
6. **制造与支付**：自体单例单批的 COGS 与产能，决定定价下限；异体要算清"可批量化"能否抵掉编辑与筛查成本。

## 三、选型决策树（文本）

```
适应症
├─ 血液系统恶性肿瘤
│  ├─ B 细胞（CD19/BCMA）→ 自体 CAR-T 为标准；差异化看持久性、安全性、给药便利（快速制备/床旁）
│  ├─ 新靶点（GPRC5D、FcRH5、CD70、DLL3 等）→ 自体 CAR-T 或 TCE 双抗对照；先问"比现有疗法多什么"
│  └─ 异体 → 仅在有明确成本/可及性优势且能解决持久性时成立
├─ 实体瘤
│  ├─ HLA 限制性抗原（NY-ESO-1、KRAS G12V 等）→ TCR-T
│  ├─ 可切除病灶 + 高突变负荷 → TIL
│  ├─ 表面抗原（CLDN18.2、GPC3、MSLN、HER2）→ CAR-T，必须解决浸润与 TME
│  └─ 抗原异质性高 → 双靶/分泌型抗体/装甲化设计，不要单靶硬上
├─ 单基因遗传病
│  ├─ 需要终身全身表达（代谢病、凝血因子）→ 肝脏靶向 AAV 或 HSC 基因治疗
│  ├─ 中枢神经系统 → 鞘内 AAV（剂量与 DRG 毒性是主要限制）
│  ├─ 视网膜 → 视网膜下/玻璃体腔 AAV（免疫特权带来低剂量优势）
│  └─ 需要精确修复 → 离体 HSC 编辑（碱基编辑/先导编辑优先于 HDR）
└─ 肿瘤免疫/其他
   ├─ 瘤内可及 → 溶瘤病毒 ± 免疫检查点
   └─ 系统性免疫调节 → 工程化细胞（CAR-Treg、CAR-NK）
```

## 四、实体瘤为什么难（判断项目时要能说清）

1. **抗原异质性**：单靶 CAR 只清除抗原阳性克隆，阴性克隆快速扩增。
2. **浸润与基质屏障**：CAR-T 需趋化因子受体匹配、突破 ECM 与物理屏障。
3. **TME 抑制**：TGF-β、IL-10、MDSC、Treg、缺氧、腺苷通路。
4. **抗原密度低**：实体瘤抗原密度常低于血液瘤，需高亲和力或双靶协同，代价是 off-tumor 风险。
5. **TCR 路线的 HLA 限制**：覆盖人群窄，HLA 下调导致逃逸。
6. **TIL 的物理门槛**：必须有可切除病灶、足够扩增、能耐受 IL-2。

## 五、常见死法（尽调时优先排雷）

- 靶点选在正常组织低表达但关键功能位点（如与心肌、神经共享表位）。
- AAV 载荷超限，靠"截短蛋白"硬塞，效力和稳定性双输。
- 用 IIT 数据替代 GLP 毒理与工艺数据去支持 IND，被要求补做。
- 单臂数据 ORR 尚可但 DoR 短，确证性试验设计被否。
- 自体产品静脉-静脉周期 5 周以上，入组患者等不到回输。
- 异体产品没算宿主排斥，疗效只在清淋强度极高时出现，安全性不可接受。
- 放行效力 assay 与临床疗效无相关性，工艺变更后无法证明可比。
- 定价对标海外，未考虑中国支付结构，峰值销售假设高一个数量级。
